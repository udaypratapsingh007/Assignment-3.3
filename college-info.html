Computer Science Course Information

Introduction

This page gives information about the Bachelor of Computer Science course. The course teaches programming, web development and computer fundamentals.

Subjects

  • Programming Fundamentals
  • Web Development
  • Database Management
  • Data Structures
  • Computer Networks

Admission Process

  1. Fill out the online application form.
  2. Upload the required documents.
  3. Pay the application fee.
  4. Check the merit list.
  5. Complete the admission and fee payment.
